## Why

当前任务详情面板存在两个交互问题：1) 阶段推进/回退按钮与表单保存按钮堆在同一 `form-actions` 操作栏中，视觉层级混乱；看板卡片上已有状态快速切换和快速完成按钮，面板中的「▶开始处理」「✔标记完成」是冗余操作；2) 各阶段产出的文档（PRD、方案设计、测试报告）以条件判断渲染在 phase 面板内容区，没有统一的文档管理入口，不支持图片粘贴和附件关联。需要移除冗余状态按钮、保留核心阶段流转操作并独立展示、将文档改为分 tab 管理。

## What Changes

### 流程按钮优化
- **移除冗余状态按钮**：删除面板内「▶开始处理」「✔标记完成」「↩标记未完」按钮，状态变更统一在看板卡片上操作（状态标签循环切换 + 快速完成按钮）
- **独立流程操作区**：阶段推进/回退按钮从 `form-actions` 分离，在面板中独立展示（主操作：🚀 推进到下阶段；次操作：↩ 退回上阶段）
- **流程历史时间线**：面板底部展示阶段流转记录（谁在什么时间推进/回退了阶段）

### 文档区域改造
- **分 Tab 文档区**：将当前 phase 条件渲染的文档 textarea 改为固定 tab 栏（📋 需求文档 / 📝 设计文档 / 🧪 测试文档 / 📎 附件），每个 tab 独立管理内容
- **附件上传增强**：支持拖拽上传、图片粘贴（paste to upload）、附件预览（图片缩略图、文件类型图标）
- **文档与任务关联**：文档内容保存时自动关联到当前任务，附件模型中已有 `task_id` 外键，可直接复用

## Capabilities

### New Capabilities
- `workflow-action-bar`: 独立的流程操作栏，根据任务 phase+status 动态显示阶段推进/回退按钮（移除冗余状态流转按钮），附带流程时间线
- `document-tabs`: 任务详情面板中文档区域的分 tab 管理（需求/设计/测试/附件），每 tab 支持编辑和预览
